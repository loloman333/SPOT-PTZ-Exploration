# Utilizing the SPOT ROS2 Driver

!!! warning
    This document is currently a work in progress and may contain incomplete or outdated information.


When this guide was initiated, the [GitHub repository](https://github.com/bdaiinstitute/spot_ros2) for the SPOT ROS2 driver provided minimal documentation. Not much is documented on their [wiki](https://github.com/bdaiinstitute/spot_ros2/wiki), just the setup and a list of the services and topics available, with sparse explanation imo.

For this reason, this guide was created to serve as an introduction to the SPOT ROS2 driver, aiming to clarify its usage and help you navigate both the driver and ROS2.

If you have any questions about this documentation or about the driver, feel free to ask **Márk**.

***This documentation is for the 4.1.0 SDK version on f63fc807304d1db3363547dc8d43fdf31c7a449c commit id! Thus this doc is not suited for the rolling version.***
